# ResearchProject

## Problem Focus

This project focuses on:

- Developing machine learning approaches for failure classification and root-cause analysis to identify potential software faults and their underlying causes.
- Designing an automated remediation framework that selects and executes appropriate recovery actions based on detected failure conditions.
- Developing a continuous Detect → Diagnose → Remediate → Verify feedback loop to improve software reliability and reduce system recovery time.
- Evaluating the proposed approach using metrics such as detection accuracy, precision, recall, F1-score, false-positive rate, recovery success rate, and Mean Time to Recovery (MTTR).
